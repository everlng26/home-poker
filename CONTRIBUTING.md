# Участие в разработке

Спасибо за помощь Home Poker. Перед изменениями прочитайте [архитектуру](docs/ARCHITECTURE.md) и [инструкции для coding agents](AGENTS.md). Описывайте проблему или предложение в GitHub Issues и указывайте, как её воспроизвести.

## Локальная проверка

1. Установите Python 3.11–3.13 на macOS и запустите `./setup.command`.
2. Внесите изменения с учётом доменных правил в `AGENTS.md`. Бизнес-логика находится в сервисах, а не в шаблонах, JavaScript или обработчиках маршрутов.
3. Добавьте тест для изменения бизнес-инварианта или исправления ошибки.
4. Обновите документацию и запустите `./run_tests.command`.
5. Проверьте изменения в Safari на iPhone, если затронут мобильный интерфейс.

Не добавляйте в коммит базы из `data/`, резервные копии, `.env`, PIN и другие секреты. В pull request кратко опишите изменение, способ проверки и особенности миграции, если она есть.
