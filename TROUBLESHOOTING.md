# Устранение проблем

## Конструктор стеков показывает 404 или `Unexpected token '<'`

После обновления Python routes уже запущенный сервер не перечитывает автоматически. Закройте Terminal, в котором работает Home Poker, снова запустите `start.command` и обновите страницу. Наборы фишек и турниры сохраняются в SQLite и при перезапуске не удаляются. Новая версия также показывает понятное сообщение вместо технической ошибки разбора HTML как JSON.

## Телефон не открывает страницу

1. Подключите телефон и компьютер к одной домашней Wi‑Fi-сети.
2. Откройте адрес именно в Safari.
3. Не используйте гостевую сеть: она может запрещать устройствам видеть друг друга.
4. Временно отключите VPN на компьютере и телефоне.
5. Если macOS спросит о входящих подключениях Python, разрешите доступ для частной сети.
6. Откройте LAN URL вручную, если QR-код не сработал.
7. В роутере отключите Client isolation / AP isolation, если такая настройка включена.
8. Если домашняя сеть всё равно не соединяет устройства, временно используйте режим модема телефона или другую общую локальную сеть.

## QR-код открывает localhost

Если QR-код ведёт на `localhost`, откройте в браузере телефона адрес компьютера в домашней сети, например `http://172.20.10.12:8000`. В обычном сценарии приложение выбирает локальный адрес автоматически.

## Таймер не проигрывает звук

На экране display сначала нажмите «Открыть турнирный экран». Это обязательное требование браузеров: они не разрешают звук без явного нажатия пользователя.

## Не запускается setup.command

Проверьте, что установлен Python 3.11–3.13 и команда `python3 --version` работает в Terminal. Скрипт не устанавливает Python или Homebrew автоматически.

## Порт 8000 занят

Закройте другое приложение, которое использует порт 8000, либо выполните `doctor.command` для диагностики.

## Приложение не работает после выключения компьютера

Не закрывайте окно Terminal во время турнира. При повторном запуске данные и состояние таймера будут восстановлены из SQLite.
