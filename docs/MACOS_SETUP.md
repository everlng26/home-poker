# Установка на macOS

Поддерживаются компьютеры на macOS с процессорами Apple Silicon или Intel и Python 3.11–3.13. Проект не устанавливает Homebrew, Python или системные настройки самостоятельно.

`setup.command` создаёт `.venv`, устанавливает Python-зависимости и применяет миграции. `start.command` запускает сервер на `0.0.0.0:8000` через `caffeinate`, поэтому компьютер не засыпает, пока открыто окно Terminal.

`app/main.py` не является пользовательским файлом запуска. Его можно использовать только для технической проверки командой `python3 -m app.main`; обычный путь — двойной щелчок по `start.command`.

При первом сетевом запросе macOS разрешите входящие подключения Python в частной сети.
