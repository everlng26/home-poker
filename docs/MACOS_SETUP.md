# Установка на macOS

Поддерживаются компьютеры на macOS 12 и новее с процессорами Apple Silicon или Intel.

## Приложение

`Домашний покер.app` не требует Python: всё нужное лежит внутри. Данные хранятся в `~/Library/Application Support/Домашний покер` (база `poker.db`, ключ сессий, резервные копии `backups/`, журнал `logs/app.log`). Приложение собирается командой `./build_app.command` и подписано без сертификата разработчика, поэтому первый запуск нужно разрешить в «Системных настройках → Конфиденциальность и безопасность → Всё равно открыть».

Окно приложения показывает адрес для телефона и кнопку открытия турниров в браузере. Закрытие окна или «Завершить» (⌘Q) останавливает сервер; если турнир идёт или стоит на паузе, приложение сначала спрашивает подтверждение.

## Запуск из исходников

Нужен Python 3.11–3.13. Проект не устанавливает Homebrew, Python или системные настройки самостоятельно.

`setup.command` создаёт `.venv`, устанавливает Python-зависимости и применяет миграции. `start.command` запускает сервер на `0.0.0.0:8000` через `caffeinate`, поэтому компьютер не засыпает, пока открыто окно Terminal.

`app/main.py` не является пользовательским файлом запуска. Его можно использовать только для технической проверки командой `python3 -m app.main`; обычный путь — двойной щелчок по `start.command`.

При первом сетевом запросе macOS разрешите входящие подключения Python в частной сети.
