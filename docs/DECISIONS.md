# Архитектурные решения

- SQLite работает в WAL-режиме, с foreign keys, timeout и согласованными резервными копиями.
- PIN будет хешироваться `hashlib.scrypt` без дополнительной криптографической зависимости.
- При нескольких LAN-адресах сервер автоматически выберет доступный адрес для QR-кода.
- В мастере будут доступны несколько готовых структур блайндов; после выбора каждый уровень можно отредактировать.
